# 🖼️ Image Processing Application

### C++ | Object-Oriented Programming | Image Processing

An interactive **Image Processing Application** developed using C++ as a team project for the Object-Oriented Programming (OOP) course at the Faculty of Computers and Artificial Intelligence, Cairo University.

The application allows users to load, manipulate, and enhance digital images through a collection of 18 different image processing filters, all accessible through an easy-to-use interface.

## 📌 Project Overview

The main goal of this project is to apply Object-Oriented Programming concepts in building a practical image processing application.

Users can load images, select from a variety of image manipulation operations, apply different filters, and save the processed results.

The project combines fundamental image processing algorithms with structured C++ programming to provide a functional and interactive experience.

## ✨ Features

- **18 Image Processing Filters:** A collection of image manipulation and enhancement techniques.
- **Image Loading:** Load images from your local device.
- **Image Saving:** Save processed images to your desired location.
- **Interactive Interface:** Navigate through the application and select filters using an organized interface.
- **Image Manipulation:** Perform various transformations and modifications on images.

### 🎨 Implemented Filters

The application includes 18 filters and image processing operations, including:

- Grayscale
- Black & White
- Invert Colors (Negative)
- Merge Images
- Flip Image
- Rotate Image
- Darken & Lighten
- Crop Image
- Add Frames
- Resize Image
- Blur Images
- Oil Painting
- Skewness

And other image processing operations.

## 🚀 Getting Started

### Prerequisites

Before running the application, make sure you have:

- A C++ compiler (GCC / MinGW).
- Visual Studio Code or any compatible C++ IDE.
- The required project header files and libraries.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/essammarwan498-ux/Image-Processing-Assignment1.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Image-Processing-Assignment1
   ```

3. Open the project in your preferred C++ development environment.

4. Build and run the application using your configured C++ compiler.
